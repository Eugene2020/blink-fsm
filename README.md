# blink-fsm

UART-управление встроенным индикатором STM32F103 Blue Pill. 

## Устройства и подключение

- Микроконтроллер STM32F103C8T6 (Blue Pill)
- USB-UART адаптер CP2102
- Программатор STLink V2

Подключение UART-адаптера:

```
TX  - PA10
RX  - PA9
GND - GND  
VCC - 3.3V
```

## Сборка и прошивка

Нужное ПО:
- `arm-none-eabi-gcc`
- `make`
- `git`
- `minicom`

Процесс сборки и прошивки:
- Склонировать проект
- В корне склонировать библиотеку libopencm3 
`git clone https://github.com/libopencm3/libopencm3.git`
- Собрать библиотеку `cd libopencm3 && make && cd ..`
- Собрать проект `make`
- Прошить `make flash`

## Использование

Через утилиту `minicom` подключиться к STM32F103, которая подключена к ПК по адаптеру USB-UART.

`minicom -D /dev/ttyUSB0 -b 115200`

Ввести нужное количество миганий и длительность каждого мигания.

`5 1000` что означает влючить светодиод на 1000мс, отключить, напечатать вывод, повторить 5 раз.

Вывод программы:

```
[cmd] start
blink 1 
blink 2 
blink 3 
blink 4  
blink 5  
[done] blinks=5 state=IDLE
```

В процессе можно ввести команду `stop` для остановки программы и показа количества отработавших циклов.
